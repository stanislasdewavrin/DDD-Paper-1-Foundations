This directory contains the manuscript and the supporting reproducible
material for **Paper I** of the DDD series.

## What this paper claims

Five claims, each documented as either an algebraic identity, a
structural consequence of the local rule, or an internal-consistency
result verified numerically:

1. Local and global conservation of charge under the flux term, with
   the only documented source of non-conservation being the threshold
   $R_{\min}$ ($\sim 0.24\%$ over 200 ticks).
2. The interface identity $T^2 + I^2 = \chi$ as a definitional
   consequence of the angular parametrization, preserved under
   dynamical drainage to machine precision.
3. Recovery of the kinematics of special relativity in the regime
   $\chi = 1$ as an internal-consistency identity.
4. Emergence of a local direction field $\mathbf{n}_i$ from the gradient
   of node retention, with appropriate indeterminacy at strict
   symmetries.
5. Inertial relaxation of $\phi$ converges to the analytic equilibrium
   $\arctan(\lambda/\mu)$ at the predicted rate
   $\tau_{\rm ret} \ln(1/\varepsilon)$.

## What this paper does not claim

This paper makes **zero new physical predictions**. It does not
establish emergent gravity, Newton's constant, the cosmogenetic
filling cascade, off-centre observer effects, particles as
self-trapped vortices, electromagnetism, quantum phenomena, or the
unification synthesis. Each of these is the subject of a companion
paper, and is referenced as "in preparation" in `references.bib`.

## Quick start

```bash
make all      # Run all tests, generate figures, compile manuscript
make tests    # Just the four internal-consistency tests
make figures  # Just the figures
make paper    # Just compile the manuscript
make clean    # Remove auxiliary files
```

## Reproducibility

All simulations use fixed random seeds (`np.random.seed(2024)` for the
single-realization tests). Results should be reproducible to floating-
point precision on any standard scientific Python installation
(NumPy ≥ 1.20, SciPy ≥ 1.7, Matplotlib ≥ 3.5).
